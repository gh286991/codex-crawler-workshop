爬蟲原理 10–13 分鐘

網頁爬蟲的三個步驟

爬蟲把網頁中反覆出現的結構整理成可查詢的資料。

  1. 取得網頁requests 送 HTTP GET，取得狀態碼和 HTML。
  2. 解析 HTMLBeautifulSoup 找到每篇文章的標題與連結。
  3. 輸出資料csv 寫出一列一篇的檔案，供統計與通知使用。
HTTP 200 表示伺服器回應成功。程式仍要確認回應裡有預期的文章列表。

Requests 官方文件　Beautiful Soup 選擇器

爬蟲原理 13–15 分鐘

公開列表與課堂快照

  • 只讀看板列表沿「上頁」最多讀三頁，間隔 2 秒。取標題、日期、文章連結。
  • 連線前看網站規則點下方連結。使用條款看資料使用限制。robots.txt 先找適用的 User-agent，再用 Allow、Disallow 對照 /bbs/Gamesale/。
  • 連線後看 HTTP 狀態Chrome「檢查」→ Network → 重新整理 → 看主頁請求的 Status。403 是拒絕存取，429 是請求太頻繁。遇到這兩種狀態或轉址，範例就停止。

爬蟲原理 17–18 分鐘

一篇貼文在 HTML 裡長什麼樣

同一列的原始 HTML 節錄
<div class="r-ent">
  <div class="title">
    <a href="/bbs/Gamesale/M.1794414281.A.702.html">
      [ NS2] 售 薩爾達傳說 時之笛
    </a>
  </div>
  <div class="meta">
    <div class="date">11/12</div>
  </div>
</div>
  • .r-ent外層包住這一整筆貼文。
  • .title a[href]連結文字是畫面上的標題，href 是點進去的文章路徑。
  • .meta .date日期節點的文字是畫面右側的 11/12。

爬蟲原理 18–20 分鐘

從 HTML 到六個 CSV 欄位

把原頁的《時之笛》貼文整理成一個 Python 字典，再寫成一列 CSV。

欄位取值與整理同一篇貼文的結果
date取 .date 的文字，保留月／日11/12
platform取標題方括號內的文字，去頭尾空白並轉大寫NS2
action從方括號後辨識售、徵、換或贈售
status依標題是否寫明已售、洽中等字樣判定未標示
title取連結文字，統一全形與半形[ NS2] 售 薩爾達傳說 時之笛
url把 href 轉成完整網址，跨頁用它去重對應文章連結
跳過置底文、無有效連結或日期的列，以及不符合交易標題格式的列。整理後一篇文章只留一列。

哪些機票資料可以自動取得

來源怎麼取得拿到的價格
Google Flights在網頁手動查價或使用價格追蹤。robots.txt 禁止抓取部分搜尋及訂票路徑。合作夥伴提供的行程報價
Skyscanner向合作夥伴團隊申請 API 金鑰。一般比價網站的條款限制未授權的自動擷取。Indicative 是最多 4 天前的快取參考價。Live 查指定日期的行程報價。
Duffel用官方 Offer Requests API，需要存取權杖。真實票價需啟用正式帳戶。測試環境提供測試價格。正式環境可取得行程報價。
