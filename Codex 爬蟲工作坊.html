爬蟲原理 10–13 分鐘

網頁爬蟲的三個步驟

爬蟲把網頁中反覆出現的結構整理成可查詢的資料。

  1. 取得網頁requests 送 HTTP GET，取得狀態碼和 HTML。
  2. 解析 HTMLBeautifulSoup 找到每篇文章的標題與連結。
  3. 輸出資料csv 寫出一列一篇的檔案，供統計與通知使用。
HTTP 200 表示伺服器回應成功。程式仍要確認回應裡有預期的文章列表。

爬蟲原理 17–18 分鐘

一篇貼文在 HTML 裡長什麼樣

同一列的原始 HTML 節錄
<div class="r-ent">
  <div class="title">
    <a href="/bbs/Gamesale/M.1794414281.A.702.html">
      [ NS2] 售 薩爾達傳說 時之笛
    </a>
  </div>
  <div class="meta">
    <div class="date">11/12</div>
  </div>
</div>
  • .r-ent外層包住這一整筆貼文。
  • .title a[href]連結文字是畫面上的標題，href 是點進去的文章路徑。
  • .meta .date日期節點的文字是畫面右側的 11/12。

欄位取值與整理同一篇貼文的結果

url把 href 轉成完整網址，跨頁用它去重對應文章連結
跳過置底文、無有效連結或日期的列，以及不符合交易標題格式的列。整理後一篇文章只留一列。
